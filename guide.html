Quick Start & Installation

Installation wizard, default safe profile protection, and startup options.

Better Color Profile is designed for **Windows 11 and Windows 10** (both 64-bit and 32-bit). It completely replaces the native Windows colorcpl.exe applet with a high-performance modern interface.

Step 1: Download

Download the official BetterColorProfileSetup.exe with built-in SHA-256 integrity check.

Step 2: Choose Folder

Install to default location %LocalAppData%\Programs\BetterColorProfile or pick a custom folder.

Step 3: Launch & Enjoy

Optional Start with Windows and desktop shortcuts keep your calibrated display ready at all times.

Protected Default Profile Architecture

Your factory Windows sRGB profile is permanently isolated in the internal system folder (.internal\sRGB Color Space Profile.icm). It is marked strictly protected, meaning it can never be accidentally modified, renamed, or deleted. You can always revert to factory display colors in one single click.

Profile Switching (Hotkeys & Auto Detection)

Two distinct methods for setting your color profiles: manual keyboard shortcuts or automated game window detection.

Better Color Profile gives you two powerful, hardware-accelerated methods to switch between your calibrated display presets. You can choose whichever approach fits your personal playstyle best.

⚠️ Important: Choose One Method at a Time

You should decide which switching method you want to use for your games: either use Global Shortcuts (Direct Slot or Cycling) OR use Auto Game Detection. Do not use both methods simultaneously for the same game, to ensure smooth operation and prevent conflicting profile triggers.

METHOD A

Global Keyboard Shortcuts & Profile Cycling

Full Manual Control

Trigger instant profile transitions from anywhere in Windows or directly inside full-screen games with zero alt-tabbing:

🎯 Direct Profile Shortcuts

Assign a dedicated, custom hotkey to any individual profile slot directly on its card. Pressing your bound key instantly switches straight to that exact profile without delay.

🔄 Customizable Cycle Hotkey

You can set a single custom cycle shortcut to smoothly cycle forward through your active profiles one by one on the fly, rotating through your presets with just one keybind.

METHOD B

Auto Game & Window Detection

Zero Manual Effort

Link specific profiles directly to game executables. Better Color Profile monitors the active foreground window with zero background CPU overhead:

1 Enable Window Detection

Go to Options → Window Detection and enable the master switch. When disabled, zero background window tracking occurs.

2 Link Profile to Executable (.exe)

Right-click any profile card and choose “Link to Game / Window...”. Pick from open windows or click “Browse .exe...” to select game binaries (e.g. cs2.exe).

3 Automated Switch & Revert

When you focus into the game window, your calibrated profile engages automatically. When you close or minimize the game, it instantly reverts back to your protected Default Profile.

Profiles, Import & Export

Managing color profiles, exporting calibrated presets, and sharing codes with friends.

Better Color Profile makes saving, importing, and sharing display calibrations completely straightforward, with no complex directory browsing needed.

📁 Profile Groups & Organization

Organize your profiles into custom tabbed categories (Group 1, Group 2, etc.). Click the + button above your profile list to create new groups, allowing you to separate competitive gaming profiles, video editing calibrations, and night mode setups cleanly.

💾 Import & Export via Files (.icm / .icc)

Export: Click “Save .ICC Profile” in the tuner or right-click any profile card to export your calibrated Windows color profile to any folder on your computer.

Import: Drag and drop any standard .icm or .icc file (from DisplayCAL, Rtings, or monitor manufacturers) directly into Better Color Profile to add it to your slots.

📋 Import & Export via Share Code

Copy Code: Click the “Copy Share Code” button on any profile to generate a lightweight text string (e.g. BCP-XXXX-...) copied straight to your clipboard.

Apply Code: Paste any share code from Discord or forums directly into the app to instantly replicate that exact 7-slider color calibration on your monitor in one click.

Frequently Asked Questions

Answers to common questions and troubleshooting tips.

Can I get banned in competitive games for using Better Color Profile?

No. Better Color Profile interacts strictly with the Windows GDI display driver and GPU hardware color LUT (SetDeviceGammaRamp). It never hooks, reads, or injects into any game code. Kernel anti-cheats (Vanguard, BattlEye, EAC, Ricochet) view it as standard monitor hardware settings.

Why did a game reset my colors when I launched it?

Some legacy games running in Exclusive Fullscreen mode force a hardware gamma reset on launch. To keep your profile active: simply press your global profile cycle hotkey once inside the game, run the game in Borderless Windowed mode, or enable Auto Game & Window Detection which automatically reapplies your profile.

How do I restore my original monitor colors?

Click the Default Profile card in the left sidebar and click Apply, or right-click the system tray icon and select Default Profile. Your original Windows color profile is always safely stored in the protected internal directory.
