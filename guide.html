Quick Start & Installation

Installation wizard, default safe profile protection, and startup options.

Better Color Profile is designed for **Windows 11 and Windows 10** (both 64-bit and 32-bit). It completely replaces the native Windows colorcpl.exe applet with a high-performance modern interface.

Step 1: Download

Download the official BetterColorProfileSetup.exe with built-in SHA-256 integrity check.

Step 2: Choose Folder

Install to default location %LocalAppData%\Programs\BetterColorProfile or pick a custom folder.

Step 3: Launch & Enjoy

Optional Start with Windows and desktop shortcuts keep your calibrated display ready at all times.

Protected Default Profile Architecture

Your factory Windows sRGB profile is permanently isolated in the internal system folder (.internal\sRGB Color Space Profile.icm). It is marked strictly protected, meaning it can never be accidentally modified, renamed, or deleted. You can always revert to factory display colors in one single click.

100% Anti-Cheat Friendly & Kernel Driver Safety

Zero DLL injection, zero game memory access, and 0% FPS impact.

Unlike shader injectors like ReShade or custom monitor software that hooks into DirectX, Vulkan, or OpenGL pipelines, **Better Color Profile never interacts with game processes directly**:

Zero Game Injection

Never injects DLLs into game processes. Completely invisible to kernel-level anti-cheats (Vanguard, EAC, BattlEye, Ricochet, VAC).

Direct GPU LUT Control

Adjustments are applied directly to the hardware color lookup table (LUT) via official Windows GDI APIs (SetDeviceGammaRamp).

0.0ms Input Lag

Because LUT transformations are processed by display silicon inside your GPU and monitor, there is zero frame time latency.

Zero FPS Drop

Consumes 0% GPU rendering budget. Enjoy identical frame rates with enhanced visibility and vibrant color contrast.

Auto Game & Window Detection

v2.10.12

Automatic profile switching when launching games and instant revert on close.

Introduced in **v2.10.12**, you can bind any color profile to an active application or executable. Better Color Profile continuously tracks foreground windows with zero CPU consumption and applies your calibration seamlessly.

1 Enable the Master Toggle

Navigate to Options → Preferences and tick Auto Game & Window Detection. When this checkbox is unticked, zero background logic or hooks run on your PC.

2 Link a Profile to a Game or Application

On the left sidebar, right-click any profile card (Slot 1, Slot 2, etc.) and select “Link to Game / Window...”. Choose from the list of currently open windows, or click “Browse .exe...” to select any installed game executable.

3 Visual Icon Badge

Once linked, the profile card immediately renders the high-res 24×24 application icon and process name directly on the card, giving you instant visual confirmation of which profile belongs to which game.

4 Automated Default Revert

The moment you focus or tab into your game, Better Color Profile switches to that profile instantly. When you close, minimize, or Alt-Tab out of the game, it **automatically reverts back to your Default Profile** with zero manual intervention.

Profiles, Slots & Backups

Managing color profiles, importing custom ICC/ICM files, and backup paths.

All your profiles are stored in plain format directly inside your installation directory:

%LocalAppData%\Programs\BetterColorProfile\list\ • Custom calibrated profiles
%LocalAppData%\Programs\BetterColorProfile\.internal\ • Protected default Windows sRGB profile
%LocalAppData%\Programs\BetterColorProfile\slots_config.txt • Slot assignments

To import any monitor calibration profile (e.g. from DisplayCAL, Rtings, or TFTCentral), simply drag and drop the .icm or .icc file into the application or place it directly into the list\ folder.

Frequently Asked Questions

Answers to common questions and troubleshooting tips.

Can I get banned in competitive games for using Better Color Profile?

No. Better Color Profile interacts strictly with the Windows GDI display driver and GPU hardware color LUT (SetDeviceGammaRamp). It never hooks, reads, or injects into any game code. Kernel anti-cheats (Vanguard, BattlEye, EAC, Ricochet) view it as standard monitor hardware settings.

Why did a game reset my colors when I launched it?

Some legacy games running in Exclusive Fullscreen mode force a hardware gamma reset on launch. To keep your profile active: simply press your global profile cycle hotkey once inside the game, run the game in Borderless Windowed mode, or enable Auto Game & Window Detection which automatically reapplies your profile.

How do I restore my original monitor colors?

Click the Default Profile card in the left sidebar and click Apply, or right-click the system tray icon and select Default Profile. Your original Windows color profile is always safely stored in the protected internal directory.
