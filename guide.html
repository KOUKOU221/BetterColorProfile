Quick Guide

Everything you need to calibrate, switch profiles without conflicts, and fix common display issues.

Rule of Thumb: Use Global Shortcuts OR Auto Window Detection — not both for the same game.
Prevents profile conflicts

Method A: Global Shortcuts

MANUAL
  • Bind a key directly on any profile card for instant 1-tap switching, or set a single cycle shortcut in Options → Shortcuts.
  • Press Esc while capturing a shortcut box to clear it.

Method B: Auto Window Detection

AUTOMATIC
  • Turn on Options → Window Detection, then right-click any profile → Link Game Window (Browse .exe...).
  • Matches strictly by foreground executable and restores Default Profile when you alt-tab or exit.

FAQ & Fixes

Is Better Color Profile anti-cheat safe?

Yes. It writes strictly to the Windows display LUT via SetDeviceGammaRamp and mscms.dll. No game memory reads, no DLL injection, and no kernel drivers (Vanguard, EAC, BattlEye, Ricochet compatible).

How do I restore my factory monitor colors?

Apply Default Profile in the sidebar or right-click the tray icon and select Default Profile. Your original Windows sRGB profile stays read-only.

How do I move my license key to a new PC?

Click Recover My Key at the bottom of the homepage to verify your email and reset your machine binding.
